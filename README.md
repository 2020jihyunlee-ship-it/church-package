# 교회 패키지 «AX 교회학교» — v0.1 (골격)

> **선언: AI가 신앙을 대신하지 않게 하는 AX.**
> 행사가 끝나면 흩어지는 교회가 아니라, 한 권의 책과 준비된 교사가 남는 교회.

## 구성 (링크 2개 체계)

| 저장소 | 내용 |
|---|---|
| **본 저장소** | 자비스용 스킬 2종 + 워크플로우 3본 명세 |
| [godsaengbook-grace](https://github.com/2020jihyunlee-ship-it/godsaengbook-grace) | 갓생북 은혜 앱 (Next.js·별도 배포) — 리더 1명 가입, 멤버는 링크만으로 참여, 종료 시 PDF 책 자동 생성 |

## 스킬 (자비스 스킬 표준 형식)

| 스킬 | 대상 | 하는 일 |
|---|---|---|
| `skills/pbs-teacher-spirituality/` | 교사들(대학생~장년) | 교사 영성모임 — 각자 본문 직접 연구 + 서로 나눔. AI는 연구를 대신하지 않고 판만 깐다 |
| `skills/church-event-director/` | 행사 디렉터(누구든) | 성경학교·수련회 — 기획안·타임테이블·역할표·예산·조편성·안전점검·공지문 3종 |

## 설치 (자비스)

```
1. 본 저장소 clone
2. skills/ 아래 두 폴더를 자비스 스킬 디렉터리(~/.claude/skills/)로 복사
3. 워크플로우는 v1 릴리스에서 제공 예정 (workflows/WORKFLOWS.md 명세 참조)
```

## ⚠ v0.1 상태 고지 (정직한 라벨)

- 두 스킬의 **▣ 자리(현장 24년 노하우)는 증류 인터뷰 전까지 비어 있다.**
  스킬은 작동하나 임시 골격임을 스스로 출력에 표시하며, **▣가 채워진 v1.0이 정식 배포판**이다.
- 워크플로우는 명세만 실려 있다(구현은 로드맵 3~4주차).

## 윤리 (패키지 불가침)

1. AI는 신앙을 대신하지 않는다 — 성경 요약·묵상 대필·기도문 양산 없음
2. 모든 스킬에 «적대적 자기개선 + 정직한 보고» 조항 내장
3. 개인정보 최소 — 기록의 주권은 각 교회 로컬에
4. 무료 — 판매 압박 없음
